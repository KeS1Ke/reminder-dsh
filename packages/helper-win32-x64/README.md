# @kesike/reminder-dsh-win32-x64

Prebuilt Windows x64 (`x86_64-pc-windows-msvc`) native helper binary (`bin/dsh-reminder-helper.exe`) for [`@kesike/reminder-dsh`](https://www.npmjs.com/package/@kesike/reminder-dsh).

This package is installed automatically as an optional dependency on Windows x64.
