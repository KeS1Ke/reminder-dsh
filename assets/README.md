# DeepSeek Harness icon

`deepseek-harness.png` is an unchanged copy of the official Windows desktop icon:

https://github.com/deepseek-ai/deepseek-harness/blob/fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159/apps/desktop/resources/icon-windows.png

`deepseek-harness.ico` is the same image at 16, 20, 24, 32, 40, 48, 64 and 256 pixels. Notification shortcuts use it so Windows does not scale the executable's 32-pixel icon into the toast header.
